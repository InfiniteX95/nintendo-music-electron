# Nintendo Music Electron

A simple Electron wrapper for the Nintendo Music web app.

[Castlabs' "Electron for Content Security" Fork](https://github.com/castlabs/electron-releases) is used for Widevine content playing support.

## Development

You need to install NodeJS and a node package manager (e.g. NPM, PNPM)

Install dependencies :

```
npm install
```

Start the app :

```
npm run dev
```

Create a runnable application :

```
npm run package
```

Create distributable packages (installers and archives for distribution):

```
npm run make
```
